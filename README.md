## 🚀 Portfolio Features

### Design
- **Modern Framer-inspired aesthetic** with clean, professional design
- **Dark theme** with gradient accents and glass morphism effects
- **Smooth animations** and transitions throughout
- **Responsive design** that works seamlessly on mobile, tablet, and desktop
- **Interactive hover effects** on cards and buttons
- **Gradient orbs** with floating animation in the hero section

### Sections
1. **Hero Section** - Animated introduction with typing effect
2. **About Section** - Personal introduction and highlights
3. **Projects Section** - Showcase of featured work with interactive cards
4. **Skills Section** - Technical skills with animated progress bars
5. **Contact Section** - Contact information and form

### Functionality
- ✨ Typing animation for dynamic hero text
- 🎯 Smooth scrolling navigation with active link highlighting
- 📱 Mobile-responsive hamburger menu
- 🎨 Scroll-triggered animations using Intersection Observer API
- 🖱️ Custom cursor effect (desktop only)
- ⌨️ Keyboard navigation support for accessibility
- 🎭 Parallax effects on hero background
- 🔄 Animated skill progress bars on scroll
- ♿ Screen reader announcements and accessibility features
- 🎬 Reduced motion support for accessibility preferences

## 🎨 Customization Guide

### Colors
Edit the CSS variables in `styles.css` to change the color scheme:

```css
:root {
    --bg-primary: #0a0a0f;        /* Main background */
    --bg-secondary: #12121a;       /* Secondary background */
    --accent-primary: #667eea;     /* Primary accent color */
    --accent-secondary: #764ba2;   /* Secondary accent color */
    /* ... more variables */
}
```

### Content
1. **Hero Section**: Update the name and typing text array in `script.js`
2. **About Section**: Edit the text content in `index.html`
3. **Projects**: Replace placeholder projects with your own work
4. **Skills**: Adjust skill names and progress percentages
5. **Contact**: Update contact methods with your actual information

### Images
Replace the SVG placeholders in the HTML with your own images:
- About section profile image
- Project screenshots
- Skill icons
